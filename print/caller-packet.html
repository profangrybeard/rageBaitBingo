Rage Bait Bingo 2.0

Caller packet. Every page except the last goes to the Caller. The last page, the instructor key, stays with the instructor.

You are the Caller

You call numbers, you ship patches, and the house always wins. Keep this packet face down. Nobody else reads it.

Calling

Read each number off the call sheet in order. Say it twice, clearly. Check it off.

Patching

Read each patch strip word for word, then add it face up to your stack of read patches. Never explain a patch. If someone asks what it means, read it again, slower.

Play the first five calls clean. After that, the call sheet tells you when to patch. Any time a player claims bingo, drop the next patch before you check their card.

Checking a claim

Walk to the table. Read their card out loud, slowly. Find the patch that disqualifies them. There is always one.

House moves

Use each one once, whenever you like.

  • Call a number that was already called. If challenged, it was a different 14.
  • Apply a patch to one table only.
  • Misread a player's card out loud during a check.
  • Take a mark back from a player for lag.

Ending

When the instructor gives the signal, hold up the House card and call bingo. Explain nothing.

Call sheet

Left to right, top to bottom. Pink squares mean patch after that call.

Patch strips

Cut these apart. Draw them in order. Read aloud unless the strip says otherwise.

    House card

    This card never loses.

    Instructor key

    Instructor only. Each patch breaks one of the ten basic game design tools from Chapter 2 of Sharp and Macklin, Games, Design and Play.

    Debrief prompt

    Each table names three problems. For each: what happened, which tool broke, and one fix. A fix that just deletes the patch doesn't count.
